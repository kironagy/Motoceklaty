# رافع طلبات أمان — نموذج أولي

إضافة كروم: بتعلّم خطوات رفع كل نوع طلب على أمان، وبعدين تعيدها ببيانات الطلب، وتقف عند زرار الحفظ لحد ما الموظف يوافق.
التصميم الكامل: `docs/aman-uploader-design.md`.

## التثبيت
1. افتح `chrome://extensions` وشغّل وضع المطوّر.
2. دوس "Load unpacked" واختار فولدر `aman-extension`.
3. دوس على أيقونة الإضافة، هتفتح اللوحة الجانبية.

## التعليم
1. افتح صفحة طلب جديد على أمان.
2. في اللوحة اختار نوع الطلب، ودوس "ابدأ التعليم".
3. جنب كل خانة هتظهر قايمة. حدد منها: خانة من الطلب، أو قيمة ثابتة، أو ملف، أو الموظف يكتبها، أو تجاهل.
4. كمّل الرفع عادي. الضغطات والصفحات بتتسجل لوحدها، وزرار الحفظ بيتعلّم عليه "وقفة موافقة".
5. دوس "احفظ الوصفة".

## التشغيل التجريبي
اختار النوع، وحط بيانات الطلب (مؤقتًا بصيغة JSON)، ودوس "شغّل على الصفحة دي". لو أي خانة ناقصة أو مش لاقيها، الإضافة بتقف وتقول السبب.

## التجربة من غير أمان
```bash
python3 -m http.server 8765 --directory aman-extension
```
افتح `http://localhost:8765/dev/aman-step1.html` (صفحة بتقلّد أمان) و`http://localhost:8765/panel-dev.html` (اللوحة). الملف `dev/chrome-shim.js` بيقلّد واجهات كروم.

## لسه ماتعملش
- ربط بموتوبوت: سحب الطلب الجديد وقفله، وتخزين الوصفات على السيرفر.
- قراءة البطاقة آليًا.
- الفحص السابق على صفحة البحث في أمان.
- أزرار الاختيار ومربعات التعليم بتتسجل كضغطة ثابتة، مش من بيانات الطلب.
